# System Operations

## Overview
This document outlines the operational procedures for the Coffee Shop application.

## Startup
To start the application locally:

### Backend
Run the start script:
```bash
./scripts/start-be.sh
```
This will activate the virtual environment and start the Flask server on port 8000.

### Frontend
Run the start script:
```bash
./scripts/start-fe.sh
```
This will start the Vite development server on port 5173.

## Maintenance
- Ensure dependencies are up to date.
- Check logs for errors during startup.
