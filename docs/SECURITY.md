# Security Policies

## Overview
Mandatory security practices.

## Checklist
- [ ] **HTTPS**: Enforce SSL/TLS.
- [ ] **CORS**: Restrict to specific domains.
- [ ] **Rate Limiting**: Prevent abuse on API endpoints.
- [ ] **Sanitization**: Prevent SQL Injection/XSS (use ORM & Framework tools).
- [ ] **Headers**: Helmet/Secure headers (HSTS, No-Sniff).
