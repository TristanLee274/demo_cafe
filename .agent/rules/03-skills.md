# Rule: Mandatory Skills

## Core Principle
Leverage specialized agent skills to ensure high-quality output in specific domains.

## Required Skills List

### Process & Quality
1. **`concise-planning`**: Mandatory start for every task.
2. **`lint-and-validate`**: Ensure code quality and consistency.
3. **`kaizen`**: Constant improvement mindset.
4. **`systematic-debugging`**: Analytical approach to solving bugs.
5. **`git-pushing`**: Regular code synchronization.

### Frontend Engineering
6. **`frontend-developer`**: Best practices for frontend development.
7. **`ui-ux-pro-max`**: High-end aesthetics and usability.
8. **`tailwind-patterns`**: Standardized Tailwind CSS styling.
9. **`frontend-design`**: Frontend design principles and patterns.

### Backend & Architecture
10. **`senior-architect`**: System design and architecture.
11. **`architecture-patterns`**: Common architecture patterns.
12. **`api-patterns`**: Clean and RESTful API design.
13. **`architecture-decision-records`**: Documenting key decisions.
14. **`senior-fullstack`**: Robust fullstack development.
15. **`backend-dev-guidelines`**: Backend development best practices.
16. **`legacy-modernizer`**: Refactoring and modernization.

### Java & Database
17. **`java-pro`**: Java 17+ best practices and patterns.
18. **`postgres-best-practices`**: PostgreSQL optimization and best practices.
19. **`postgresql`**: PostgreSQL database operations and queries.

### Advanced Tech
20. **`rag-engineer`**: Retrieval Augmented Generation implementation.
21. **`vector-database-engineer`**: Vector store management.

### Testing & Automation
22. **`test-driven-development`**: Test-first approach.
23. **`browser-automation`**: E2E testing with Playwright.
