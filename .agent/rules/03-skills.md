# Rule: Mandatory Skills

## Core Principle
Leverage specialized agent skills to ensure high-quality output in specific domains.

## Required Skills List

### Process & Quality
1. **`concise-planning`**: Mandatory start for every task.
2. **`lint-and-validate`**: Ensure code quality and consistency.
3. **`kaizen`**: Constant improvement mindset.
4. **`systematic-debugging`**: Analytical approach to solving bugs.
5. **`git-pushing`**: Regular code synchronization.
6. **`code-review-checklist`**: Systematic self-review before finalized changes.

### Frontend Engineering
7. **`frontend-developer`**: Best practices for frontend development.
8. **`ui-ux-pro-max`**: High-end aesthetics and usability.
9. **`tailwind-patterns`**: Standardized Tailwind CSS styling.
10. **`frontend-design`**: Frontend design principles and patterns.

### Backend & Architecture
11. **`senior-architect`**: System design and architecture.
12. **`architecture-patterns`**: Common architecture patterns.
13. **`api-patterns`**: Clean and RESTful API design.
14. **`architecture-decision-records`**: Documenting key decisions.
15. **`senior-fullstack`**: Robust fullstack development.
16. **`backend-dev-guidelines`**: Backend development best practices.
17. **`legacy-modernizer`**: Refactoring and modernization.

### Java & Database
18. **`java-pro`**: Java 17+ best practices and patterns.
19. **`postgres-best-practices`**: PostgreSQL optimization and best practices.
20. **`postgresql`**: PostgreSQL database operations and queries.
21. **`database-architect`**: Advanced database architecture and scaling.
22. **`database-design`**: Schema design and normalization.

### Advanced Tech
23. **`rag-engineer`**: Retrieval Augmented Generation implementation.
24. **`vector-database-engineer`**: Vector store management.

### Testing & Automation
25. **`test-driven-development`**: Test-first approach.
26. **`browser-automation`**: E2E testing with Playwright.
27. **`e2e-testing-patterns`**: Best practices for end-to-end testing.
28. **`test-fixing`**: Strategies for fixing flaky or broken tests.
