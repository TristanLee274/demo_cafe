# Rule: Mandatory Skills

## Core Principle
Leverage specialized agent skills to ensure high-quality output in specific domains.

## Required Skills List

### Process & Quality
- **`concise-planning`**: Mandatory start for every task.
- **`lint-and-validate`**: Ensure code quality and consistency.
- **`kaizen`**: Constant improvement mindset.
- **`systematic-debugging`**: Analytical approach to solving bugs.
- **`git-pushing`**: Regular code synchronization.

### Frontend Engineering
- **`frontend-developer`** & **`react-patterns`**: Best practices for React.
- **`tailwind-patterns`**: Standardized styling.
- **`ui-ux-pro-max`** & **`frontend-design`**: High-end aesthetics and usability.
- **`form-cro`**: Conversion rate optimization for forms.

### Backend & Architecture
- **`senior-architect`** & **`architecture-patterns`**: System design.
- **`backend-dev-guidelines`** & **`senior-fullstack`**: Robust backend logic.
- **`api-patterns`**: Clean and restful API design.
- **`architecture-decision-records`**: Documenting key decisions.

### Advanced Tech
- **`rag-engineer`**: Retrieval Augmented Generation implementation.
- **`vector-database-engineer`**: Vector store management.
- **`legacy-modernizer`**: Refactoring and modernization.

### Testing
- **`test-driven-development`**: Test-first approach.
- **`browser-automation`**: E2E testing with Playwright.
