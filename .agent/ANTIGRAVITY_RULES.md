# Antigravity Rules & Guidelines

## 1. Project Structure
The project follows this strict directory structure:
- `src/`: Contains all source code.
  - `src/frontend/`: Frontend application (React/Vite).
  - `src/backend/`: Backend logic (Python/FastAPI/Flask).
- `test/`: Unit, Integration, and E2E tests.
- `scripts/`: Operational scripts (`start-be.sh`, `start-fe.sh`, `build.sh`).
- `docs/`: Documentation (`README.md`, `SYSTEM_OPERATIONS.md`, `ERD.md`, `IMPLEMENT_PLAN.md`).

## 2. Operational Workflow
- **Read First**: Always start by reading relevant `.md` files (specifically `docs/IMPLEMENT_PLAN.md` and related docs) before writing code.
- **Plan**: Use `concise-planning` to outline steps before execution.
- **Track**: Update `docs/IMPLEMENT_PLAN.md` immediately after completing a task.
- **Language**: If the conversation is not in English, translate and respond in the appropriate language (e.g., Vietnamese).
- **Git**: Push changes to Git upon task completion.
